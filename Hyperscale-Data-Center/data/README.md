## Data-use guidance

- Always identify the selected **data date** when reporting project-level indicators.
- Do **not** sum project BAC, CPI or SPI across reporting snapshots.
- Derive CPI and SPI from aggregate monetary values: **CPI = ΣEV / ΣAC**, **SPI = ΣEV / ΣPV**.
- Verify schedule dates and activity classifications against the relevant Primavera P6 update.
- Treat cost loading, planned-value time-phasing and forecast assumptions as portfolio modeling decisions.

See [methodology and QA checklist](../docs/methodology.md). This README documents intended use; it does not certify the workbook's contents or formulas.
