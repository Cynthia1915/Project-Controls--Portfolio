
# Monte Carlo Schedule Risk Simulator V1

This project demonstrates a simplified Monte Carlo Schedule Risk Analysis approach using Primavera P6 schedule data and Python.

## Objectives
- Simulate schedule uncertainty
- Generate 1,000 Monte Carlo simulations
- Estimate P50, P80, and P90 confidence levels
- Quantify schedule uncertainty
- Demonstrate probabilistic schedule forecasting

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Primavera P6 schedule data
